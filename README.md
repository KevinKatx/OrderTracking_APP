## Introduction

Food Stop KCO is a SME located within the Philippines, Ilocos Sur they are a business that is concerned with the delivering of food products which were ordered through the use of their FaceBook page
or through their phones. Their operations are only within the premises of Ilocos Sur, our application aims to create a way for the business to digitally record their logs of orders, and products alongside
which customers are prompting these orders.

## Installation

There is currently no way for users to obtain the current application as there is no user interface being created and the application is solely for the usage of the enterprise owners.
```
Step 1:
Clone current repository
Step 2:
Install Android Studio
Step 3:
Open repository in Android Studio
Step 4:
Allow Developer Tools within Android Device
Step 5:
Allow USB tethering
Step 6:
Connect Phone to Computer
Step 7:
Run the Application in Android Studio and set device as the output of application.
Step 8:
Done.
```
